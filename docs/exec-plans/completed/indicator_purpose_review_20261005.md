# 지표 수집 목적과 적합성 검토

상태: 완료. 기준일: 2026-10-05. 연구 후보 설계.

## 요청과 완료 조건

사용자는 API 수집 가능성 점검에 이어, 지표를 왜 모으고 무엇을 체크할지 먼저 명확히 한 뒤 검토하도록 지시했다. 신규 API 호출 파일럿과 DDR5 고객 카드는 보류한다.

- 경제적 질문, 관계의 양 당사자, 관측 대상과 판단 후속 행동을 정의한다.
- 기존 34개 번호 지표와 6개 가족 측정 계약을 ID에 고정해 수집 적합성을 검토한다. 합계를 고유 경제 지표 수로 부르지 않는다.
- 중요도와 실제 수집 준비를 분리하며 핵심 질문의 공개 공백을 남긴다.
- 이전 날짜 JSON과 manifest는 불변으로 보존하고 현재 안내만 갱신한다.
- 독립 목적 검토와 참조·범위·무결성 검증 뒤 기존 승인 범위에 따라 커밋·푸시·main 통합한다.

## 작업 분담

- root: 목적 계약·전체 매핑·안내·검증·저장소 통합.
- purpose_manager: 읽기 전용 목적 및 수렴 검토.
- ai_usage_api_feasibility: 읽기 전용 AI 7개와 금융 10개 관측 적합성 검토.
- macro_cycle_metrics: 읽기 전용 전력/정책 14개, 대만 3개, 무역/산업/소재 6개 계약 검토.

## 범위

SK hynix 중심 산업·상품·고객 관계 학습과 무료 관측 설계다. 실수요·주문량, 실증 선행성, 반복 수집, H1 편입·Gate 6 승인, 법적 효력 판정은 이번 작업의 결과가 아니다. 가격·재무 외의 채택·계약·공정·허가·가동 사건을 핵심 공백으로 검토한다. 신규 계정·키 발급은 실행하지 않는다.

## 진행 기록

- 기존 API 접근 문서와 공개 packet의 범위·지표 ID를 확인하고 세 독립 읽기 검토를 시작했다.
- 공식 Comtrade preview, HF 다운로드 정의, USAspending endpoint, Eurostat API 문서를 재열람했다. 원문 새 API 호출은 하지 않았다.
- 7개 질문과 34개 번호 지표·6개 가족 계약의 목적·관계·체크·후속 행동·금지 해석·준비 전제를 등록표에 고정했다. 중요도·직접성·접근 준비·실증 선행성은 별도로 유지했다.
- 목적 검토의 REWORK에 따라 핵심/KOSIS 직접성, 7개 검토 객체 표현, ETF 그림, 과거 DDR5 권고/현재 안내를 수정했다. 검토자가 실제 파일 재확인 후 CONTINUE로 판정했다.
- AI/금융 독립 검토는 17개 ID/원 pointer와 기존 API 7개 JSON 바이트를 대조해 PASS했다. 공개 연락처·키·절대 로컬 경로 검출은 0건이다.
- 로컬 검증은 40개 원 참조·문서/등록표 분류 일치·미승인 상태·후속 행동/금지 해석·UTF8 LF·기존 7개 API 입력 hash를 확인했다. 기존 API 검증으로 더 앞선 6개 immutable 입력도 보존을 확인했다.
- 새 데이터는 목적 등록표·manifest이며 기존 34+6을 독립 지표 40개로 집계하지 않는다. API 호출 파일럿·DDR5 카드·반복 수집은 구현하지 않았다.
- 저장소 커밋·푸시·main 통합은 이전 사용자 승인 범위다. 최종 commit/PR/main 상태는 Git 이력과 첨부 PR에서 확인한다. 저장소 통합은 Evidence·H1 승인이 아니다.

## 다음 작업 하나

한국 반도체 산업의 KOSIS 생산/출하/재고 exact 표·항목·분류·단위를 먼저 확인해 관세청/Comtrade 교역과 비교 가능한 범위·불가능한 연결을 고정한다. 무료 metadata/문서 검토부터 시작하며 KSIC·HS를 같은 상품·회사·거래로 가정하지 않는다. 본 수집은 그 계약 확정 뒤의 별도 작업이다.
