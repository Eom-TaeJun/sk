# 반도체 산업 거시 구조 기준판 정리

완료일: **2026-10-04**. 범위: 공개 연구 문서·출처 영수증·탐색 링크. 사용자는 거시 범위 점검의 후속 정리와 GitHub 커밋·푸시를 요청했고, 기존 main 통합 지시는 유지된다.

## 해결한 문제

기존 공급망 연구는 AI/HBM 대표 관계와 수집 후보를 갖췄으나 제품·사업모델·공정·수요시장·지역을 공통 기준으로 설명하는 산업 학습 문서가 없었다. 새 기준판은 이 다섯 축에 하이닉스의 상품, 기업 21개의 기능과 근거 성숙도, 지역·소재·시장 비교의 경계를 연결한다.

메모리 사이클 문서는 수요·재고·가격·판매 비트·투자·공급·배치·ETF 배분을 18개 관측 후보로 나눈다. 각 후보에 목적, 단위·범위, 수집처, 무료/유료·인증·접근 상태, 주기·연결 키와 반증 조건을 기록했다. 우리의 측정 설계와 공개된 사건·회사 주장·예측은 각각 구분한다.

## 근거와 보존

- 신규 원문 8건: OECD PDF 3건, SIA PDF 1건, WSTS 전망 PDF 1건, WSTS HTML 2건, WSTS 역사 XLSX 1건.
- SHA-256·크기·실제 URL·확인 시각·표시 발행일·locator·제한된 발췌를 기록했다. 직접 OECD HTML 요청 실패 2건과 공식 PDF 성공은 별도 접근 결과다.
- WSTS 전망본의 2025 과거연도/2026 예측 8개 기준값과 2026-07 세계 월별 billings 1개만 기록했다. 월값·3MMA·연간 전망, 백만 달러·천 달러를 구분했다.
- 무료 지역별 총 billings와 유료 상세 제품 구독을 다른 소스로 표시했다. 원문 PDF/HTML/XLSX 전체는 공개 저장소 밖에 보관한다.
- 기존 직무·HBM 원문 영수증은 재사용하고 기존 지도·기관 검토의 후보 상태·기준일은 유지했다. 기존 69개 주체·58개 관계의 JSON을 변경하지 않았다.

## 검증과 남은 범위

변경 범위에 맞춰 원문 8건의 hash·bytes·발췌, 제품 분류와 WSTS PDF 2쪽 수치의 시각 검토, 18개 고유 지표 ID, source ID·로컬 링크 85개·공개 파일 11개의 운영경로/개인정보·manifest 해시를 확인했고 통과했다. 독립 검토에서 공급 식의 수율 중복 해석 위험과 다음 작업의 범위 차이를 발견해 수정했다. Markdown은 Git의 텍스트 줄바꿈 정책을 따르므로 문서는 경로로 참조하고 고정 바이트 해시는 `-text` 정책의 연구 데이터에만 적용했다.

기존 공급망 연구 validator(기존 아티팩트 8개)와 diff 공백 검사를 실행했고 통과했다. 소프트웨어 코드·런타임을 바꾸지 않아 전체 소프트웨어 시험은 반복하지 않았다. 문서·패키지 검증은 회사 주장 자체의 독립 감사·예측력·인과효과 검증을 뜻하지 않는다.

거시 학습 구조는 정리했으며 현재 시장의 통합 관측 패널, 같은 기간·분모의 경쟁 점유율, 전 세계 제품별 시설 능력, 직접 주문·고객 배정, 연속 수집·개정 이력과 선행성 검증은 남아 있다. H1 데이터셋·Gate 6·정식 Evidence·Strong Inference 상태는 바꾸지 않는다.
