# AI 기술 변화와 하이닉스 상품 요구의 연결표

시작일: **2026-10-04**. 상태: 완료. 사용자는 AI 기술 발전에 따른 공급망 동향을 파악하기 위해 부족한 공통 연결표를 작성하도록 승인했다. 기존 연구자료의 커밋·푸시·main 통합 지시는 이 후속에도 적용한다.

## 목적과 범위

하이닉스 영업·마케팅·상품기획·신제품사업화 학습을 위해 **AI 기술·업무 변화 → 시스템 병목 → 상품·요구 사양 → 기명 채택 → 공급 조건**을 연결한다. 기존 GB300·서버 DRAM·SSD 자료를 재사용하고 무료 공식 기술 원문을 필요한 범위에서 보완한다. 기술 원리·회사 계획·시험 결과·실제 사건과 우리의 가설은 별도로 남긴다.

## 역할과 완료 조건

Root는 통합 연결표·자료 품질·직무 질문·GitHub 반영을 맡는다. 조사 담당은 상품 채택과 소프트웨어 조건을 별도 JSON으로 작성한다. 독립 관리 담당은 시작·중간·마무리에서 발산·수렴·과잉 해석을 점검한다.

1. 각 연결 행에 업무 조건·병목·메모리 계층·사양·경제 주체·채택 단계·공급 공백·관측 목적을 남긴다.
2. 회사 발표·기술 설명·관측된 사건·우리의 가설을 국소적으로 구분한다.
3. 공개 원문 bytes/hash/locator/기간·문서 버전을 기록하고 기존 근거의 hash·기준일을 보존한다.
4. 반론으로 양자화·캐시 재사용·구성 차이를 확인하고 시험 효과를 구매량·총수요로 환산하지 않는다.
5. 관측별 정의·무료 수집 경로·연결 키·변경 확인 주기·확인하지 못하는 범위를 제시한다.
6. 관리 검토의 실제 수정 내역, 데이터/참조/원문 hash·발췌/상대 링크/개인정보 검사와 기존 연구 validator 결과를 남긴다.

전체 기술·기업의 전수 목록, 자동 수집·상시 관리, 고객 주문·수율·CAPA 추정, H1/Gate 6·선행성 승격은 범위 밖이다.

## 실제 결과와 검증

공통 연결 일곱 가지, 소프트웨어 조건 네 개, 별개 상품 채택 사례 네 개를 저장했다. 신규 원문 여섯 개를 원본 HTTP 바이트와 짧은 발췌로 확인했고 기존 출처 열한 개는 원 패킷·hash·날짜를 보존한 참조로 재사용했다. 오래된 기술 원리와 2025/2026 backend 차이를 본문에 명시하라는 관리 REWORK를 반영했다.

[연결표](../../research/supply_chain/ai_technology_memory_links.md), [관리 검토](../../research/supply_chain/research_convergence_review.md), [자료 manifest](../../../data/research/ai_technology_memory_links/2026-10-04/manifest.json)에 결과·경계를 남겼다. 신규 출처의 원문 hash·크기·발췌, 참조 ID·조건/사례·기존 입력 hash·false 승인 플래그·고객 값 null·문서 날짜/backend·상대 링크·공개 파일 개인정보 검사를 통과했다. 기존 연구 validator도 PASS했다.

실제 runtime 시험·고객 이용/주문량·전수 산업 수급·자동 수집·선행성은 수행하지 않았다. 코드·H1 데이터셋을 변경하지 않아 전체 pipeline과 H1 실증을 이번 확인 범위로 삼지 않는다.
