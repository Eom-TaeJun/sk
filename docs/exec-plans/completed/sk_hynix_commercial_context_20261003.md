## 요청과 변경

사용자는 공급망 지도의 우선 목적을 하이닉스의 2026년 하반기 영업·마케팅·상품기획·신제품사업화 직무에 필요한 산업·상품 배경지식 학습으로 명확히 했다. README·AGENTS·Master와 공급망 안내의 목적을 이에 맞추고 기존 OpenAI–CoreWeave 단일 계약 실험을 보조 사례로 보존했다.

`docs/research/supply_chain/sk_hynix_commercial_role_context.md`에 공식 2026 공고·JD, 상품군, 고객 문제, 구매/설계/인증/통합/사용 역할, 기명 사례, 무료 자료 수집 순서와 학습 카드 필드를 정리했다. HBM·서버 DRAM·eSSD를 우선 학습한다. 기존 후보 지도 JSON과 H1 Track·Gate 6 승인 상태는 유지한다.

`data/research/sk_hynix_commercial_context/2026-10-03/sources.json`은 10개 후보 출처의 실제 URL·해시·크기·날짜·locator와 제한된 발췌를 제공한다. HTML 9개는 실제 HTTP 200 수집 후 발췌·해시를 검사했다. 이미지형 공식 JD PDF 24페이지는 렌더로 직접 읽었고 원본 8,776,399 bytes의 SHA-256을 기록했다. 공식 원문 전체를 공개 저장소에 추가하지 않았으며 공개 bundle만으로 전체 바이트 재생을 보장하지 않는다.
