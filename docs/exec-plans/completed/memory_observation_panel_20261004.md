# 메모리 분기 관측표와 목적 수렴 점검

시작·완료일: **2026-10-04**. 상태: 완료. 사용자는 거시 구조의 후속 관측표 작성과 독립 관리 에이전트의 목적·발산·수렴 점검을 요청했다. 기존 GitHub 커밋·푸시·main 통합 지시는 이 연구 자료의 후속에도 적용한다.

## 목적과 범위

하이닉스의 영업·마케팅·상품기획·신제품사업화 학습에서 수요·공급 설명에 실제로 쓸 수 있는 공개 관측을 처음 저장한다. 달력상 **2026년 2분기**의 SK hynix와 삼성전자 공식 자료를 대상으로 재고, DRAM/NAND 비트 출하·ASP 설명, 현금 설비 지출과 투자 계획을 구분한다.

재고는 6월 30일 기말 잔액, 출하·ASP는 Q2와 비교 분기, 현금 지출은 Q2 또는 상반기 누적의 원래 기간을 보존한다. 같은 날짜여도 삼성전자 전체와 메모리 중심 기업의 사업 범위는 다르다. 원문에 없는 제품별 값·고객 물량은 만들지 않는다. 검토 자료에서 숫자를 찾지 못한 상태와 전체 공개 여부를 구분한다.

## 실행과 관리 역할

- Root: 기간·정의 계약, 두 기업 자료의 통합, 직무 질문과 데이터 품질 검토, 저장소 반영.
- 기업별 조사 담당: 공식 무료 원문 탐색·수집·발췌·관측 후보와 접근 실패 기록. 각기 별도 파일을 맡는다.
- 독립 관리 담당: 시작·중간·마무리에서 목적 적합성, 필요한 발산, 근거의 수렴, 미지원 해석을 점검하고 실제 수정 내역을 남긴다.

이번 관리 역할은 Codex의 실제 서브에이전트로 실행한다. Hermes 설치·접속·상시 감시나 새 Agent Execution Harness를 구현했다고 표현하지 않는다. 관리 검토는 정식 Evidence·Strong Inference·H1 판정의 사람 승인을 대체하지 않는다.

## 완료 조건

1. 두 기업의 원문 영수증과 관측 후보에 기간·단위·사업/제품 범위·발췌·locator·hash·공개 시점을 기록한다.
2. 실제 값·범위 표현·정성 설명·가이던스·검토 범위 내 미발견을 별도 상태로 저장한다.
3. 직접 비교 가능한 셀과 조건이 다른 셀을 구분하고 고객·상품·공급 일정의 학습 질문으로 연결한다.
4. 관리 담당의 실제 초기·중간·최종 검토와 반영한 수정을 문서로 남긴다.
5. 출처/관측 ID·원문/파일 hash·단위·기간·비공개 값·상대 링크·공개 파일의 개인정보를 검사하고 기존 연구 validator를 실행한다.
6. 원문 전체·자격증명·개인 자료·H1 데이터셋을 공개 변경에 포함하지 않는다. 반복 수집·선행성·사업 권고는 이 첫 관측표의 완료 조건이 아니다.

## 산출물과 실제 수정

- [첫 분기 관측표](../../research/supply_chain/memory_observation_panel_2026q2.md): 두 기업의 2026Q2 핵심 여섯 항목과 비교 기간·전망·투자 계획을 분리했다.
- [회사 관측과 비교 계약·manifest](../../../data/research/memory_observation_panel/2026-10-04/manifest.json): 기업별 12개, 총 24개 후보 항목. 미발견·정성·가이던스·다른 기간도 포함하므로 24개 당기 수치라는 뜻이 아니다.
- [독립 목적 검토](../../research/supply_chain/research_convergence_review.md): 초기·중간·마무리 검토와 실제 REWORK/CONTINUE/DEFER를 기록하고 작업 지침에 지속 기준을 반영했다.
- 프레젠테이션에서 찾지 못했던 삼성 당기 비트·ASP를 공식 스크립트에서 보완했다. 실적발표 사건일·검토보고서일·최초 공개 시점을 분리하고 DDR5 인증·전시 탑재를 별개 사례로 고쳤다.
- SK의 음수 현금 취득 값과 삼성의 양수 유출 규모/별도 원 부호 필드를 비교 계약에 명시했다. 원 데이터의 부호를 임의로 덮어쓰거나 값을 변환하지 않았다.

## 검증과 한계

원본 HTTP 바이트 다섯 출처와 공식 연결 경로 HTML 세 개의 hash·크기를 대조했고, SEC 도구 텍스트 한 개는 별도 정규화 캡처로 대조했다. SEC 직접 원본 요청의 HTTP 403 실패는 보존한다. 여섯 원출처의 제한된 발췌를 캡처 본문에 대조했고 각 출처의 영어 발췌는 25단어 이하다. 통합 검사를 통과했다. 문서 상대 링크 95개와 공개 파일 13개를 확인했다. 검사 범위는 관측·참조 ID, 원 단위·기간·부호·null/밴드·후보 상태, immutable JSON 세 개의 manifest, 문서 상대 링크와 공개 파일의 개인정보 패턴을 대상으로 한다.

기존 `python scripts/validate_supply_chain_research.py`도 PASS했다. 코드·runtime·H1 데이터셋 변경이 없어 전체 pipeline이나 경험적 H1 검증은 이번 확인 범위에 포함하지 않는다. 원문 전체는 재배포하지 않으며 개별 회사의 실제 보고 정확성·독립 회계 감사·예측력·반복 수집·Gate 6 승인으로 표현하지 않는다. 최초 공개 시점·제품별 재고·같은 SKU 가격·고객별 주문·메모리 시설 배분의 공백이 남는다.
