# 하이닉스 상품·고객·직무 관점의 공급망 학습

기준일: **2026-10-03**. 상태: **`RESEARCH_CANDIDATE_NOT_GOVERNED_EVIDENCE`**.

## 1. 지금 이 작업을 하는 이유

목적은 **SK하이닉스의 상품을 고객의 문제와 연결하여 영업·마케팅·상품기획·신제품사업화 직무의 판단을 이해하는 것**이다. 세계 지도는 기업·공장·고객·규제의 위치를 보여 주는 표현층이다. 먼저 “누가 무엇을 위해 어떤 상품을 선택하고, 어떤 사양·인증·구매·공급 과정을 거치는가”를 설명할 관계가 필요하다.

사용자가 2026-10-03 이 목적을 명확히 했다. 이전의 폭넓은 돈흐름·전력·소재 조사는 고객의 구매 조건, 상품 가치 또는 공급 일정과 연결해 재사용한다. [기존 고객 약정 실험](decision_purpose.md)은 보조 사례로 보존한다. 투자자의 ETF 배분은 고객의 메모리 구매와 별도 관측층이다.

2026-10-04 거시 범위를 먼저 정리해 달라는 요청에 따라 [반도체 산업 거시 구조](semiconductor_macro_structure.md)와 [메모리 사이클·수집 지표](memory_cycle_signal_plan.md)를 추가했다. 아래 직무·상품 근거의 기준일을 현재 실적으로 갱신하지 않고, 산업 분류와 현재 관측값의 공백을 함께 읽는다.

같은 날 [첫 분기 관측표](memory_observation_panel_2026q2.md)와 [독립 목적 관리 기록](research_convergence_review.md)을 추가했다. 공급자 전체·제품군 지표는 고객별 주문·사양의 산업 배경으로 읽는다. 당시 제안한 DDR5 인증·전시 사례의 구체화는 이후 사용자 지시에 따라 보류했다.

[AI 기술 변화와 상품 요구의 연결표](ai_technology_memory_links.md)는 그 사이의 공통 조사틀이다. 업무·소프트웨어 조건에서 병목과 상품 요구를 확인한 뒤 인증·채택·구매·공급 사건을 조사한다. GB300의 호스트 메모리와 Xeon용 DDR5, 기명 SSD 활용과 시험 조건을 혼합하지 않는다.

2026-10-05 [산업 전파 경로 점검](semiconductor_industry_transmission_routes.md)은 메모리·로직·아날로그·전력·RF/광 제품과 파운드리·EDA/IP·후공정 기능을 나누고, 전력 규제·국가 간 협력·항공우주의 대표 관계가 고객 요구·공급 일정에 연결되는 조건을 보완한다. 당시 DDR5 카드로 좁히려던 후속 제안은 현재 보류하며 산업 연결과 관측 계약을 먼저 확인한다.

완성 기준은 기업 수나 API 수가 아니다. 상품별로 **고객 문제 → 요구 사양 → 관계 주체 → 채택 단계 → 공급 위험 → 직무별 질문**을 근거와 함께 설명할 수 있어야 한다. 학습 노트, 회사가 발표한 주장, 검증된 분석 결과와 실제 수행 성과는 각각 구분한다.

최신 상태의 한 예로, [2026-07-29 실적 발표](https://news.skhynix.com/en/q2-2026-business-results/)는 HBM4의 2분기 대량 출하와 HBM4E의 상반기 샘플 출하를 구분한다. 이는 그 날짜의 **회사 발표**다. 10월 고객별 물량·단가·납품 상태 또는 독립 검증을 의미하지 않는다. **SRC-HY26-Q2**.

## 4. 고객 역할부터 나누는 관계 지도

관계의 관측 단위는 **상품 세대 × 고객 플랫폼/사용 목적 × 관계 또는 채택 사건**이다. 국가와 기업 이름만으로 끝내지 않는다.

```text
최종 서비스·업무의 요구
    → 클라우드/기업의 시스템·예산 결정
    → 칩·플랫폼 사양 결정 + OEM/ODM의 시스템 통합
    → 메모리 요구 사양·호환성·고객 인증
    → 구매·공급·출하

하이닉스 상품
    ← 제조·패키징·검사·장비·소재의 공급 조건
    ← 고객 시설의 전력·냉각·인허가·가동 일정
```

이는 확인할 관계의 구조이며 모든 거래가 같은 순서로 진행된다는 주장이 아니다. 한 회사는 여러 역할을 할 수 있다. 주문서·청구서의 법적 구매자가 공개되지 않았다면 브랜드나 최종 사용자를 대신 넣지 않는다.

## 7. 지도와 학습 카드에 남길 필드

- 상품: 제품군·세대·SKU·상품 단위·사양·표준·사용 목적.
- 주체: 공개된 법인/브랜드와 역할; 구매자·설계자·검증자·통합자·최종 사용자·판매자·공급 파트너를 별도 기록.
- 관계: 특정 상품·플랫폼, 고객 문제, 원문이 확인한 협업·지원·인증·채택·구매·출하의 범위.
- 단계·시간: 원문 단계, 사건일, 공개일/정밀도, 조사일, 측정 기간, 미래 목표일. 단계마다 독립 사건을 보존.
- 지리: 확인된 고객/제조/패키징 부지와 좌표 출처·정밀도; 본사를 공장·DC로 대체하지 않음.
- 근거·공백: Source ID, URL, 짧은 원문 발췌, locator, 원문 해시, 회사 주장·계획·시험 범위, 미확인 항목과 다음 질문.
- 직무 의미: 영업·마케팅·상품기획·사업화 중 어떤 질문을 돕는가? 이 부분은 우리의 해석으로 표시.

**기술 → 고객 효익 → 구매 조건 → 채택 단계**를 말로 설명할 수 있는지 점검한다. 예를 들어 “HBM 대역폭이 높다”에서 끝내지 않고, 해당 플랫폼의 요구, 검증 조건, 공급 일정과 공개 공백을 설명한다. 실제 고객 내부 구매 정보·단가·수율·원가·CAPA 배정이 없으면 미확인으로 남긴다.
