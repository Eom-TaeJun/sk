# 하이닉스와 삼성전자의 메모리 분기 관측표

관측 기간: **2026년 2분기**. 조사일: **2026-10-04**. 상태: **`RESEARCH_CANDIDATE_NOT_GOVERNED_EVIDENCE`**.

이 표는 [거시 산업 구조](semiconductor_macro_structure.md)와 [18개 지표 계획](memory_cycle_signal_plan.md) 중 재고(MC07), 판매 비트(MC08), 회사 평균판매가격 ASP(MC09), 투자·설비 취득(MC16)을 실제 공개 자료에 연결한 첫 관측이다. 하이닉스의 영업·마케팅·상품기획·신제품사업화 학습에서 **제품별 물량·가격 설명을 공급 준비와 구분하고, 다음에 어떤 고객 문제를 확인할지 정하는 데** 사용한다.

양사는 같은 달력 분기를 보고하지만 회사 전체의 사업 범위와 제품 구성은 다르다. 이 표로 업체의 수요 강도·납기·가격 경쟁력·공급 능력을 순위화하지 않는다. 현재 10월의 고객 주문을 직접 관측한 표도 아니다. 보고된 당기 실적, 다음 분기 전망과 연간 계획을 나누어 읽는다.

## 기간과 원문 상태

| 구분 | 적용한 기간과 범위 | 원문의 상태 |
| --- | --- | --- |
| 당기 실적 | 2026-04-01부터 2026-06-30까지 Q2; QoQ는 Q1 대비 | 회사가 발표한 실적·설명. 발표자료의 잠정·외부 검토 전 조건 보존 |
| 재고 잔액 | Q2 말 2026-06-30; 비교 기말은 별도 관측 | 연결 장부금액. 생산자 재고 비트·고객 재고와 다름 |
| 현금 설비 취득 | Q2 또는 상반기 누적 2026-01-01부터 06-30까지 | 원 기간·현금흐름표 항목·부호를 보존. 서로 다른 기간을 자동 비교하지 않음 |
| 투자 계획 | FY2026 또는 회사가 명시한 목표 기간 | 집행된 현금·설치·가동·판매 가능 공급과 별도 |

하이닉스 발표는 **2026-07-29**, 삼성전자 실적발표 사건은 **2026-07-30**의 공식 IR 경로를 사용했다. 삼성 연결 중간재무제표의 **검토보고서일은 2026-08-13**이며, 해당 PDF 버전의 최초 공개일은 확인되지 않았다. 따라서 그 재무제표의 정확한 재고·상반기 현금 취득 값을 7월 30일에 이미 공개된 정보로 소급하지 않고 삼성 관측의 `known_at`은 `null`로 보존한다. 공개목록의 연도 분류일이나 컨퍼런스콜 예정 시각, HTTP 수정 시각을 PDF 최초 게시 시각으로 대신하지 않는다. 확인된 날짜의 정밀도와 미확인 공개 시점을 구분한다.

발표 슬라이드와 이후 재무제표는 검토 수준·반올림·기간 표시가 다를 수 있다. 각 관측에는 사용한 문서와 단위를 남기고, 서로 다른 정밀도의 값을 합쳐 더 정밀한 값처럼 만들지 않는다.

데이터 영수증: [하이닉스](../../../data/research/memory_observation_panel/2026-10-04/sk_hynix.json), [삼성전자](../../../data/research/memory_observation_panel/2026-10-04/samsung.json). 재고·현금 취득의 원 단위와 보고 정밀도를 확인한 뒤 결합한다. 재무제표의 추가 관측은 발표자료를 덮어쓰지 않고 별도로 저장한다.

## 관측을 고객과 상품의 질문으로 수렴시키기

다음은 **우리의 학습 해석과 후속 질문**이다. 회사가 직접 공개한 고객별 주문·사업 권고가 아니다. 양사의 비트 출하와 ASP 증가 설명은 확인했으나 특정 고객의 수요·메모리 구매량·가격 조건은 확인하지 않았다.

| 직무 관점 | 이번 관측으로 생기는 질문 | 추가로 필요한 기명 근거 |
| --- | --- | --- |
| 영업 | 회사 전체 출하 증가가 내가 맡을 서버 플랫폼의 구매·납기와도 연결되는가? 재고 잔액 증가 중 고객이 필요로 하는 상품이 포함되는가? | 상품·플랫폼별 구매 법인, 인증·채택·출하 사건, 공급 일정. 총재고를 납기 보장으로 쓰지 않음 |
| 마케팅 | 회사 ASP 상승에서 고객이 지불하는 가치는 대역폭·용량·전력·저장 I/O 중 무엇인가? 상품 구성의 변화와 동일 상품 가격의 변화가 구별되는가? | 같은 플랫폼·사용 업무·시험 조건의 사양과 구매 가치. 평균 ASP를 경쟁사 SKU 가격으로 쓰지 않음 |
| 상품기획 | 서버 중심 상품 구성과 모바일·PC 수요가 달라질 때 어떤 용량·규격·플랫폼을 별도로 설계해야 하는가? | 제품군별 요구 사양·로드맵·폼팩터·출시 일정. 모든 DRAM·NAND를 AI 수요로 합치지 않음 |
| 신제품사업화 | 투자·장비 준비가 새 상품의 고객 인증과 상업 출하 조건까지 이어졌는가? | 같은 상품·공정의 샘플, 인증, 패키징·검사 준비, 실제 출하. 투자액을 인증 완료·공급량으로 환산하지 않음 |

반론을 위한 발산도 포함한다. 삼성 발표자료는 서버 중심 상품 구성과 함께 모바일·PC 수요의 일부 완화를 **전망**으로 제시한다. 이 설명을 현재 모든 최종시장의 수요 증가로 일반화하지 않는다. **SRC-MC-SAM26Q2-PRESENTATION**, PDF 7쪽 결과와 H2 전망 칸. 하이닉스의 HBM·서버 DRAM·eSSD와 모바일·PC 제품은 각각 다른 고객·사용 목적을 확인해야 한다.

제품·고객을 좁힐 첫 대상은 **서버 DDR5를 중심으로 Intel Xeon 6 인증 사례와 Dell R770 전시 탑재 사례를 각각 조사하는 것**이다. 기존 **SRC-HY26-INTEL / SRC-HY26-DELL**의 회사 발표는 각각 플랫폼 인증·전시 탑재까지 확인한다. 두 사례의 동일 SKU 여부, 일련의 납품·구매 거래, Intel의 모듈 구매 또는 Dell의 실제 구매량·출하량은 확인되지 않았다. 공급자 분기 관측은 이 조사 대상의 산업 배경으로 사용한다. [기존 상품·고객 근거](sk_hynix_commercial_role_context.md)를 참고한다.

## 목적 관리와 수집의 경계

사용자의 요청에 따라 독립 관리 담당을 두고 시작·중간·마무리에서 범위와 해석을 점검했다. [관리 검토 기록](research_convergence_review.md)에 실제 판단과 수정 내역을 남긴다. 공식 발표의 다른 문서를 찾아 필요한 관측을 보완하는 발산은 수행했고, 세 번째 업체·긴 역사 패널·ETF·신규 API 확대는 현재 표의 목적에 비추어 뒤로 미뤘다.

최초 슬라이드 검토에서 찾지 못한 삼성 비트·ASP를 발표 스크립트에서 찾아 관측을 갱신했다. 이는 검토 범위가 넓어진 이력이다. 특정 문서에 없다는 사실을 전체 공개 여부의 결론으로 쓰지 않는다. 제품별 재고·실제 메모리 전용 현금 집행·고객 물량은 여전히 별도 확인이 필요하다.

| 이번에 한 일 | 남아 있는 범위 |
| --- | --- |
| 두 기업의 같은 달력 분기 원문과 관측 후보 저장 | 계속 갱신되는 시장 패널·역사적 개정 이력 |
| 수치·범위·전망·계획·사업 범위 구분 | 같은 SKU 가격·제품별 물량·고객/시설 배분 |
| 네 직무의 상품·고객·공급 질문으로 연결 | 실제 영업 제안·내부 구매 정보·확정 사업 권고 |
| 독립 관리 검토와 수정 내역 기록 | 상시 자동 관리, Hermes 설치·가동, 선행성 검증 |

자료는 후보 연구 기록이며 기존 H1·Gate 6·정식 Evidence 상태를 바꾸지 않는다. 무료 IR 페이지·PDF·공개목록 경로를 썼으며 새 계정·API 키 발급은 필요하지 않았다. 원문 전체는 재배포하지 않고 공개 URL·제한된 발췌·locator·해시를 기록한다. 원본 HTTP 바이트와 웹 도구가 읽은 텍스트는 서로 다른 획득 방식이며 출처 영수증에서 구분한다.

[비교 계약](../../../data/research/memory_observation_panel/2026-10-04/comparison_contract.json)은 여섯 핵심 항목의 관측 참조와 비교 조건을, [공개 파일 manifest](../../../data/research/memory_observation_panel/2026-10-04/manifest.json)는 관측 수·파일 무결성·수집 경계를 설명한다. 무결성 검사·관리 판정은 회사 보고의 독립 감사·예측력·인과효과를 검증한 결과가 아니다.
