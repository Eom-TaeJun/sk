# Recruiter Signal Map

| 구현/산출물 | 내가 한 판단 | 증명하는 역량 | 직무 연결 |
|---|---|---|---|
| Source Registry | Source와 Evidence를 분리하고 hash/locator를 강제 | 근거 검증·추적 | 시장·고객 정보 분석 |
| RAG | Precision보다 sentence-to-source trace를 MVP 기준으로 선택 | 문제 목적에 맞춘 AI 단순화 | Demand Forecast 근거 회수 |
| Graph | Graph DB 없이 2-hop Evidence subgraph 구현 | System thinking·범위 통제 | 상품기획/Marketing |
| Signal Dictionary | Directness·Independence·Temporal·Scope·Contradiction rubric 선택 | Signal Quality 판단 | Demand Forecast |
| Contradiction Register | sample/qualification/volume/first claim을 자동 화해하지 않음 | 반론·오류 통제 | 신제품사업화/영업 |
| Evidence Governance Harness | human approval 없는 자동 PROMOTED를 발견하고 차단 | AI Governance·실패 수정 | AI 기반 문제해결 |
| Agent Adapter | 특정 runtime보다 deterministic Core rule을 먼저 검증 | 기술 종속성 통제 | 지속 모니터링 기반 |
| Decision Memo | fact별 Evidence ID와 미확인 조건을 함께 표시 | 판단 번역 | Qualification/TTM/Customer Priority |
| Replay Test | 동일 입력의 state/graph/trace hash 검증 | 재현성·검증 습관 | Forecast/Scenario |
| Evidence Review Manifest | 전체 승인 대신 Evidence별 reviewer·decision·level·reason을 강제 | AI 결과 통제와 책임 추적 | 영업/마케팅 판단 승인 |
| Promotion Policy | A~D/E/F마다 승격 조건을 다르게 고정 | Evidence quality에 따른 판단 강도 조절 | 시장정보 검증·리스크 통제 |
| Temporal State Diff | 2025 Evidence를 보존하고 2026 Source로 confidence/edge/decision state만 갱신 | 시간축 분석·판단 업데이트 | TTM/Demand Forecast/Supply Risk |
| Known Unknown 보존 | mass shipment에서 qualification/share/price/volume을 추정하지 않음 | 공개정보 한계 인식 | 신제품사업화/고객전략 |
